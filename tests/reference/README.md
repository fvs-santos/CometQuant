# Statistical references

`v1/` preserves the historical one-way protocol. `v1/slides.csv` deliberately
contains two technical slides for every treatment/repetition; both are averaged
before the inferential tests.

The checked `v1/expected.json` values were produced by
`python scripts/calculate_reference_results.py --version v1` with SciPy 1.13.0. That script
does not import the CometQuant engine: it invokes SciPy independently and
calculates ANOVA sums of squares and Pearson-test power with the noncentral t
distribution. The complete fixture was cross-validated with R 4.6.1 using
`v1/reference_analysis.R` and can be checked again with
`npm run test:reference:r -- --version v1`. R is not part of the application runtime.

R and SciPy can differ in their last reported digits, especially for Tukey HSD.
Engine tests use tolerances at the precision stored in `expected.json`.

## Version 2 block protocol

`v2/slides.csv` has exactly three independent experiments, a negative reference,
a positive validation control, three compound concentrations, and two technical
slides per cell (30 rows). One 10 uM slide in block 3 is incomplete. Its valid
companion slide keeps the cell and the block in the analysis.

`v2/expected.json` is generated by:

```powershell
python scripts/calculate_reference_results.py --version v2 --output tests/reference/v2/expected.json
```

The script does not import `python/cometquant_analysis.py`. It independently
aggregates valid slides, calculates balanced-RCBD sums of squares, planned
contrasts with common residual MSE/df, nominal 95% intervals, Holm adjustment,
the separate validation RCBD, block-adjusted matrix OLS trend, exact
Friedman/Page permutation tests, and the arcsine-sqrt transformed sensitivity
analysis. The base R oracle in `v2/reference_analysis.R` independently fits the
same models with `lm`, `anova`, `confint`, and `p.adjust`, and computes the
exact Friedman/Page p-values by enumerating all `(k!)^n` within-block rank
permutations in base R. Validate either protocol with:

```powershell
python scripts/validate_reference_with_r.py --version v2
python scripts/validate_reference_with_r.py --version v1
```

The default version for both reference scripts is v2. The v2 oracle was checked
with SciPy 1.13.0 and R 4.6.1. Runtime code only uses NumPy/SciPy APIs available
in the pinned Pyodide stack (NumPy 1.26.4 and SciPy 1.12.0).

## Analysis contract v2

Input `studyDesign` requires `version: 1`, `status: "configured"`,
`primaryReferenceTreatmentIndex`, ordered
`primaryTreatmentIndices`, optional `validationComparison` with
`referenceTreatmentIndex` and `treatmentIndex`, `alpha: 0.05`,
`alternative: "two-sided"`, `pAdjustment: "holm"`, and
`trendReferenceAsZero: true`. Every primary dose has a finite numeric
`concentration` in the `treatmentMetadata` item identified by `treatmentIndex`.
Treatment labels are never parsed for dose.

`run_all_analyses` returns strict JSON with exactly these top-level keys:

```json
{
  "analysisSchemaVersion": 2,
  "protocol": {},
  "population": {},
  "descriptive": {},
  "scores": {},
  "blockAnova": {},
  "primaryComparisons": {},
  "controlResponse": {},
  "doseTrend": {},
  "nonParametric": {},
  "transformedAnalysis": {},
  "charts": {
    "scores": "<PNG base64>",
    "differences": "<PNG base64>",
    "classes": "<PNG base64>"
  }
}
```

`population.blocks[].cells[]` preserves `replicateNumber`, treatment index,
expected/recorded/counted, valid/complete, invalid/incomplete and absent slide
counts, the cell score, and technical-replication completeness. Primary block
exclusions contain structured reasons and treatment identities. `scores.cells`
contains only the complete primary block population while retaining each block
identity and number of slides used.

`blockAnova` reports `score ~ treatment + block`, common `MSE`, residual df, and
treatment/block/residual rows. `primaryComparisons.comparisons[]` reports both
means, treatment-minus-reference difference, standard error, t, df, nominal
95% bounds, raw p, Holm p, direction and decision; `omnibusGateUsed` is false.
`controlResponse` has its own two-treatment block ANOVA and unadjusted comparison
without assay-validity classification. `doseTrend` reports
`score ~ block + concentration (linear)`, including reference dose zero, plus a
partial R² for concentration after adjusting for block. `nonParametric` runs the
exact permutation Friedman test and the exact Page L trend test over the primary
population (reference plus doses, excluding the positive control), with Page's
direction derived from the assay type. `transformedAnalysis` re-runs the block
ANOVA, planned comparisons, and dose trend on the arcsine-sqrt scale as a
variance-stabilizing sensitivity check. Every non-estimable section has
`performed: false` and a structured `reason: {"code": "...", "detail": "..."}`.
NaN and infinities are forbidden.
